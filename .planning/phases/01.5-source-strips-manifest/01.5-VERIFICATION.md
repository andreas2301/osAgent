## TDD discipline lessons logged

1. **lib.sh local-with-self-referential-default bug** — `local pattern="$1" file="$2" ctx="${3:-$file does NOT…}"` triggered `set -u` "file: unbound variable" because the inline default referenced `$file` while `file` was being declared in the same statement. Fixed by separating `local` declarations. First TDD test run caught it.
2. **`assert_no_grep` tightening** — initial pattern matched the explanatory comment that named the dropped dep (e.g., `opentelemetry-otlp` in the strip-rationale comment). Tightened to `^opentelemetry-otlp\s*=` for actual TOML key-assignment lines. Second TDD lesson.
