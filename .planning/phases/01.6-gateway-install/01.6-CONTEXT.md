<decisions>
## Implementation Decisions

- **OS-MDashboard dependency on `/ws/chat`** — verified via `chat-relay.ts` reading. The gateway must keep `/ws/chat` and `paired_tokens` auth even though we drop everything else.
- **TLS termination delegated to systemd + nftables** — the gateway's `tls.rs` is dropped because we terminate at the host layer, not in-process. Simpler, less attack surface in the gateway.
- **Plan-then-execute discipline applied to install-guide edit** — per install-guide CLAUDE.md hard rule. Touch/Change/Impact/Rollback emitted before the ansible task was created.
- **`meta: end_play` guard at M1** — install_osagent.yml is a structural template. M2 (engineer parity) fills binary URL + SHA256 and removes the guard.

</decisions>
